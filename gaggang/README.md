# GAGGANG

High Quality Text Gags.

A mobile first React + Vite Unicode gag generator. No backend required.

## Features

- Random gag generator
- Category filters
- Search
- Favorites
- Recently used
- Copy to clipboard
- Native share when available
- Keyboard shortcut: Space = random gag
- Local persistence via localStorage
- Responsive dark UI
- 100+ seeded gags
- Ready for GitHub and Vercel

## Run

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Deploy

Import the repository into Vercel. Vercel supports Vite/React deployments, and this project includes a `vercel.json` for the static build output.

You can also upload the project ZIP through Vercel Drop.
